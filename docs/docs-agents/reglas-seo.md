# Reglas de SEO técnico

Propósito: definir los estándares de posicionamiento técnico, metadatos, datos estructurados, sitemap, favicon y etiquetas de compartición del monorepo.

## HTTPS

- Forzar HTTPS: redirección 301, HSTS y sin contenido mixto.

## Metadatos

- Meta títulos y descripciones únicos por página.

## Datos estructurados

- Datos estructurados JSON-LD, validados con Rich Results Test.

## Indexación

- Sitemap y robots.txt.
- Ficha de Google si aplica.

## Identidad visual

- Favicon en formatos modernos.

## URLs y compartición

- URLs canónicas.
- Open Graph.
- Twitter Cards.
- hreflang si aplica i18n.
